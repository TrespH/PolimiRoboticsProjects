MAP CONVERSIONS:

- map7.pgm and map7.yaml are the maps produced with SLAM Toolbox.

- cropped.pgm and cropped.yaml are the cropped versions of the maps (generated by crop_map.cpp), necessary to align the RViz and Stage maps.

- cropped_cleaned.png is the cropped map with single black pixels (which could represent unrealistic obstacles) removed. It has been converted to PNG format and is the one used for navigation. These two operations were done using GIMP.
